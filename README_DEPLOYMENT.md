# ALSKwela A&E 2027 — Elementary LS1 English (90 questions)

## Publish to GitHub Pages
1. Create a **new** public repository, suggested name `alskwela-ls1-english-reviewer-elementary`.
2. Extract the ZIP and upload `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, and `.nojekyll` **directly to the repository root**; do not upload only the ZIP.
3. Under **Settings → Pages**, choose `Deploy from a branch`, branch `main`, and folder `/(root)`.
4. Add the published HTTPS link to the Elementary LS1 English card in ALSKwela (Open Link action).
5. On Android, open the URL **directly in Chrome**, not only inside Glide, and confirm `Offline files saved successfully.`
6. Select Chrome `Install app` or `Add to Home Screen` where available; check the Home Screen label `Elem A&E LS1 English`.
7. Enable airplane mode, open the installed reviewer, complete sample questions, review Taglish feedback, and export a PDF.

## Notes
- App cache and saved progress have distinct Elementary LS1 identifiers and cannot overwrite JHS LS1 data.
- Every trial has 30 unique items, 9 Easy / 15 Moderate / 6 Challenging and all 13 competencies.
- Fixed Sets A, B, C partition all 90 items; randomized trials sample across the 90-item bank.
- Options are reshuffled **per trial**; explanations remain tied to their content.
- Practice and personal progress remain local. A PDF report is created on the learner's device; there is no server gradebook or cloud sync.
- Questions are independent mock items, pending educator review and learner pilot-testing, **not** official 2027 A&E test items.
- A Chrome shortcut may still work offline after the app cache finishes, even if `Install app` is unavailable on one device.
- In case of an update, save current reports before replacing app files. Keep this repo name and PWA path to preserve the installed app identity.
